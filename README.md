# CUTLAB Studio Ultra

עורך סושיאל בעברית עם ציר זמן רב-שכבתי, עריכת טקסט מתקדמת, מעברים, פילטרים, מדבקות, אודיו, שמירת פרויקט וייצוא WebM.

## תצוגה בדפדפן
[פתח את CUTLAB Studio Ultra במחשב](https://htmlpreview.github.io/?https://github.com/yemot-ai/-/blob/main/CUTLAB_STUDIO_ULTRA.html)

אפשר גם להוריד את קובץ `CUTLAB_STUDIO_ULTRA.html` ולפתוח אותו ב-Chrome/Edge, או להוריד את חבילת המקור ולפתוח את `index.html`.

## התקנת Android
1. פתחו את [GitHub Actions](https://github.com/yemot-ai/-/actions).
2. בחרו את הריצה האחרונה בשם **Build CUTLAB Studio Ultra Android APK**.
3. אחרי שהריצה הסתיימה בהצלחה, הורידו את ה-Artifact בשם `CUTLAB-STUDIO-ULTRA-Android-APK`.
4. חלצו את ה-ZIP והתקינו את `app-debug.apk` במכשיר Android.
5. בגרסת Android, שמירת פרויקט או וידאו פותחת חלון שמירת קבצים של המכשיר.

## יכולות
- ייבוא וידאו, תמונות ושמע.
- ציר זמן נפרד לקליפים, טקסט, מדבקות ואודיו; פיצול, שכפול, מחיקה ושינוי אורך.
- עיצוב טקסט: גופנים, גדלים, צבעים, גרדיאנט, רקע, קו מתאר, צל, יישור, סיבוב ומיקום.
- מעברי Fade, Slide, Zoom, Wipe, Flash, Spin ו-Glitch.
- בהירות, ניגודיות, רוויה, פילטרים ויחסי מסך לרשתות חברתיות.
- שמירת/פתיחת פרויקט בקובץ `.cutlab` הכולל מדיה מיובאת.
- ייצוא וידאו WebM, בהתאם ליכולות הדפדפן.

## גבולות הגרסה
זו גרסת Studio עצמאית ולא שיבוט מלא של מוצר מסחרי. כתוביות AI, מעקב אובייקטים, הסרת רקע בענן ומקודד MP4/4K חיצוני אינם כלולים.
