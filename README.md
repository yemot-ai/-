# Android Video Studio

פרויקט אפליקציית Android לעריכת וידאו, עם ממשק בעברית ותמיכה בעבודה מקומית במכשיר.

## מצב הפרויקט

זהו שלד ראשוני. המטרה היא לבנות בהדרגה אפליקציה עם בחירת סרטון, תצוגה מקדימה, חיתוך בסיסי וייצוא MP4. עדיין אין להתייחס לפרויקט כאל APK מוכן להתקנה.

## בנייה

הפרויקט מיועד להיבנות באמצעות Android Gradle Plugin ו-JDK 17. לאחר הוספת קובצי האפליקציה וה-workflow, GitHub Actions יוכל לבנות APK ולצרף אותו כ-artifact.

## פרטיות

עיבוד המדיה מתוכנן להתבצע במכשיר, ללא העלאת הסרטונים לשרת.
