# CUTLAB Studio

עורך וידאו בעברית עם ממשק עבודה מקומי וכלי עריכה מרכזיים. קובץ המקור המלא והפרויקט לאנדרואיד נמצאים ב-`CUTLAB_STUDIO_SOURCE.zip`.

## תצוגה במחשב
הורידו את `CUTLAB_STUDIO_SOURCE.zip`, חלצו אותו ופתחו את `index.html` ב-Chrome או Edge עדכני.

## בניית APK
פתחו **Actions → Build Android APK**. לאחר שההרצה הסתיימה בהצלחה, הורידו את ה-Artifact בשם `CUTLAB-Android-APK`; בתוך קובץ ה-ZIP נמצא `app-debug.apk`.

הגרסה כוללת ציר זמן לקליפים, חיתוך, פיצול, שכפול, שינוי מהירות, טקסט, פילטרים, התאמות תמונה, מוזיקת רקע, שמירה מקומית וייצוא וידאו דרך יכולות הדפדפן. זו גרסה ראשונית שימושית ולא שיבוט מלא של כל יכולות CapCut.
