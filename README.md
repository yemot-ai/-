# CUTLAB Studio

עורך וידאו בעברית שעובד מקומית, עם ציר זמן, חיתוך, פיצול, שכפול, מהירות, טקסט, פילטרים, התאמות תמונה, מוזיקת רקע, שמירת פרויקט וייצוא וידאו.

## תצוגה במחשב
בחבילת המקור המצורפת לשיחה: הורידו את `CUTLAB_STUDIO_SOURCE.zip`, חלצו אותו ופתחו את `CUTLAB_תצוגה_מקדימה.html` או את `index.html` ב-Chrome/Edge. העותק המלא של קובצי המקור נשמר בחבילת ZIP. במאגר GitHub קובצי המקור מקודדים בתוך `.source_parts/` כדי ש-GitHub Actions יוכל לבנות את האפליקציה מחדש.

## התקנת Android
1. פתחו את [Actions במאגר](https://github.com/yemot-ai/-/actions).
2. פתחו את הריצה האחרונה בשם **Build Android APK**.
3. אחרי שהריצה הסתיימה בהצלחה, הורידו את ה-Artifact בשם `CUTLAB-Android-APK`.
4. חלצו את ה-ZIP והעבירו את `app-debug.apk` למכשיר Android. פתחו את הקובץ ואשרו התקנה אם המכשיר מבקש זאת.
5. בתוך האפליקציה בוחרים סרטונים, עורכים ומייצאים. באנדרואיד, שמירת וידאו/פרויקט פותחת את חלון שמירת הקבצים של המכשיר.

## איך נבנה ה-APK
GitHub Actions משחזר את חבילת המקור, מוסיף תמיכה בשמירה דרך Android Storage Access Framework, בודק תחביר JavaScript ובונה APK באמצעות JDK 17 ו-Gradle 8.9.

## מצב וגבולות
זו גרסה שימושית ראשונית של עורך וידאו, **לא שיבוט מלא של CapCut**. אין בה את כל תכונות ה-AI, מעקב האובייקטים, הכתוביות האוטומטיות וספריית האפקטים של מוצר מסחרי. פורמט הייצוא (MP4 או WebM) תלוי ביכולות Android System WebView/Chrome של המכשיר.
