# קול־סטודיו — פיתוח קול אופליין

אפליקציית אימון קולי מקומית עם ממשק בעברית, תרגילים מובנים, הקלטה, כוונון גובה צליל, מטרונום ויומן.

## תצוגה בדפדפן
[פתח תצוגה מקדימה](https://htmlpreview.github.io/?https://github.com/yemot-ai/-/blob/main/voice-studio/index.html). אפשר להוריד את \`index.html\` ולפתוח ב-Chrome או Edge. בדפדפן, הקלטה ומיקרופון דורשים הרשאת מיקרופון והקשר מאובטח (HTTPS); ה-APK משתמש בממשקי Android המקומיים.

## APK
פתחו [GitHub Actions](https://github.com/yemot-ai/-/actions), בחרו את הריצה האחרונה של **Build Voice Studio Offline Android APK**, והורידו את artifact \`VOICE-STUDIO-Android-APK\`. חלצו את ZIP והתקינו \`app-debug.apk\`.

## תכונות
- תרגילים: חימום עדין, נשימה, דיקציה, דיוק צליל ותהודה.
- טיימר לתרגיל ויומן תרגול מקומי.
- הקלטה, השמעה ומחיקה של קבצים מקומיים ב-Android.
- כוונון גובה צליל בזמן אמת דרך המיקרופון; התדר הוא הערכה.
- תווי דוגמה מסונתזים, מטרונום עם BPM משתנה ומדידת Tap Tempo.
- מועדפים, סטטיסטיקת דקות, ימי תרגול וייצוא יומן.
- אין הרשאת אינטרנט ואין העלאת נתונים לשרת.
- מסך רספונסיבי, ניווט תחתון וכפתורים גדולים לנגני Android עם מסך קטן.

## תאימות
minSdk 23 (Android 6.0 ומעלה, כולל Android 10), בכפוף ליכולות המכשיר ול-WebView. איכות המיקרופון משפיעה על הכוונון.

## פרטיות וזהירות
הקלטות נכתבות לתיקייה הפרטית של האפליקציה. ניקוי נתוני האפליקציה עלול למחוק הקלטות. היומן נשמר ב-localStorage של WebView. עצור תרגול אם יש כאב, צרידות או אי־נוחות. זהו כלי תרגול כללי, לא כלי רפואי.
