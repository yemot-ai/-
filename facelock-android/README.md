# נעילה באמצעות זיהוי פנים

אפליקציית Android לנעילת אפליקציות נבחרות באמצעות זיהוי פנים מקומי.

## קישורים
- תצוגת Chrome: `preview/index.html`
- קוד Android: `source-parts/part01.b64` (ארכיון המקור משוחזר בבניית GitHub Actions)
- APK: לשונית Actions → הריצה האחרונה של **Build FaceLock Android APK** → Artifact בשם `FACELOCK-ANDROID-APK`.

## יכולות
- זיהוי פנים מקומי באמצעות מודל MobileFaceNet ו־ML Kit Face Detection.
- מספר פרופילי פנים מורשים, עם כמה דגימות לכל פרופיל.
- בדיקת חיות בסיסית באמצעות אתגר מצמוץ.
- אחסון וקטורי פנים מוצפן ב־Android Keystore.
- נעילת אפליקציות שנבחרו, קוד גיבוי והגדרת רגישות.

## מגבלות
האפליקציה אינה מחליפה את מסך הנעילה המקורי של Android ואינה פותחת את כל המכשיר. היא נועלת אפליקציות נבחרות בלבד באמצעות הרשאות Usage Access ו־Display over other apps. ייתכנו הבדלים בין יצרני מכשירים ובין גרסאות Android.

זיהוי RGB ובדיקת מצמוץ אינם הגנה ביומטרית חומרתית או הגנה מוחלטת מפני התחזות. יש להשאיר קוד גיבוי פעיל ולבדוק תחילה באפליקציה לא חשובה.

נתוני הזיהוי נשמרים מקומית ומוצפנים. התמונות אינן נשלחות לשרת.
